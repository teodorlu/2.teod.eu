# Agent demos

An agent demo demonstrates or explains how something works.

## agent-demos index.html
After an agent-demo, update `agent-demos/index.html`.
Keep linked demos sorted.

## Isolation
Agent demos are standalone HTML files in `agent-demos/`, and must not be used / referenced by application code.
Each demo links back to agent-demos/index.html.

## Brevity
Avoid labels if you can, no label means it works for both English and Norwegian
Be brief: either don't explain the demo in the demo, or add a single sentence.
