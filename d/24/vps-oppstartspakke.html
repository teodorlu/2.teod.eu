1 finn på server-navn
2 lag VPS på Hetzner, putt inn egen public key
  → skriv ned IP
3 putt server-IP i ~/.ssh/config
  → verifiser, ssh
4 pek domene til IP
  → ping IP / ping domene
5 installer Caddy
  → caddy --version
  → systemctl status caddy
6 få Caddy til å servere /var/www/domene på forespørsler til domene (se ./Caddyfile)
  → /etc/caddy/Caddyfile (se ./Caddyfile)
  → systemctl cat caddy
7 systemctl reload caddy
8 putt filer i /var/www/domene
9 besøk domene


Bonus gitt tid: vedlikehold
Metode: task-runner med SSH og rsync


installer Caddy, kilde https://caddyserver.com/docs/install#debian-ubuntu-raspbian

	apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
	curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
	curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
	apt update
	apt install -y caddy
	systemctl enable --now caddy

Caddyfile

	domene {
		root * /var/www/domene
		file_server
	}
